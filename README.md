## 🛠️ Developer Setup

### Prerequisites
- Java 17+  
- Maven  
- MongoDB Atlas  

---

### Environment Variables

Create a `.env` file:

```env
MONGO_URI=
DB_NAME=
CLOUDINARY_URL=
MAIL_USERNAME=
MAIL_PASSWORD=
AWS_ACCESS_KEY=
AWS_SECRET_KEY=
```

> ⚠️ Never commit `.env`. Use `.env.example`.

---

### Run Locally

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
mvn clean install
mvn spring-boot:run
```
